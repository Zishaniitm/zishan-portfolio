## Getting Started

Clone the repository:

```bash
git clone https://github.com/Zishaniitm/zishan-portfolio.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build production version:

```bash
npm run build
```

Start production server:

```bash
npm run start
```
